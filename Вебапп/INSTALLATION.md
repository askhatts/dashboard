# ИНСТРУКЦИЯ ПО УСТАНОВКЕ ВЕБА-ПРИЛОЖЕНИЯ ДЛЯ АБАЙСКОЙ ОБЛАСТИ

## 📋 Шаг 1: Подготовка структуры папок

Создайте следующую структуру в `F:/Сделано/Аналитика/Вебапп/`:

```
Вебапп/
├── launcher.R                    ← Главный launcher (скачайте)
├── app.R                         ← Приложение (скачайте)
├── R/
│   └── 01_setup_database.R       ← Скрипт создания БД (скачайте)
├── data/
│   └── geodata/
│       ├── kaz_admbnda_adm2_unhcr_2023.shp    ← Ваши шейп-файлы
│       ├── kaz_admbnda_adm2_unhcr_2023.shx
│       ├── kaz_admbnda_adm2_unhcr_2023.dbf
│       ├── kaz_admbnda_adm2_unhcr_2023.prj
│       └── kaz_admbnda_adm2_unhcr_2023.cpg
```

## 📥 Шаг 2: Скачайте файлы

1. **launcher.R** → положите в корень `F:/Сделано/Аналитика/Вебапп/`
2. **app.R** → положите в корень `F:/Сделано/Аналитика/Вебапп/`
3. **01_setup_database.R** → положите в `F:/Сделано/Аналитика/Вебапп/R/`

## 📦 Шаг 3: Переместите шейп-файлы

Скопируйте ВСЕ файлы шейпа в `F:/Сделано/Аналитика/Вебапп/data/geodata/`:

```
kaz_admbnda_adm2_unhcr_2023.shp
kaz_admbnda_adm2_unhcr_2023.shx
kaz_admbnda_adm2_unhcr_2023.dbf
kaz_admbnda_adm2_unhcr_2023.prj
kaz_admbnda_adm2_unhcr_2023.cpg
```

⚠️ **ВАЖНО**: Нужны ВСЕ файлы (.shp, .shx, .dbf, .prj, .cpg)!

## 🔧 Шаг 4: Установите пакеты R

Откройте RStudio и выполните:

```r
# Установка необходимых пакетов
install.packages(c(
  "shiny", 
  "shinydashboard", 
  "DBI", 
  "RSQLite", 
  "sf",          # ← Важно для работы с геоданными
  "dplyr", 
  "leaflet", 
  "plotly", 
  "DT", 
  "readxl"
))
```

⏱️ Установка займет 5-10 минут.

## 🚀 Шаг 5: Запуск приложения

В RStudio выполните:

```r
setwd("F:/Сделано/Аналитика/Вебапп")
source("launcher.R")
```

Появится меню:
```
==========================================
  МЕНЮ ЗАПУСКА ПРИЛОЖЕНИЙ
==========================================
1. Запустить главное приложение (Дашборд)
2. Пересоздать базу данных
3. Выход
==========================================
```

### При первом запуске:

Выберите **1** → Приложение автоматически:
1. Прочитает шейп-файл Казахстана
2. Отфильтрует 10 районов Абайской области
3. Создаст SQLite базу данных
4. Загрузит 30 медицинских организаций
5. Откроет веб-приложение в браузере

## ✅ Что должно получиться:

### База данных `data/abai_region.sqlite` содержит:

**10 районов Абайской области:**
1. Семей (город)
2. Абайский район
3. Аксуатский район
4. Аягозский район
5. Бескарагайский район
6. Бородулихинский район
7. Жарминский район
8. Кокпектинский район
9. Курчатов (город)
10. Урджарский район

**30 медицинских организаций** с привязкой к районам

**Реальная геометрия** (полигоны границ районов из шейп-файла)

### Веб-приложение включает:

📊 **Вкладка "Обзор"**
- KPI: количество районов, МО, государственных/частных
- График распределения МО по районам
- Круговая диаграмма типов МО
- Хороплет-карта с полигонами районов

🗺️ **Вкладка "Карта"**
- Интерактивная карта с реальными границами районов
- Маркеры МО с цветовой кодировкой по типу
- Кластеризация маркеров
- Всплывающие окна с информацией
- Контроль слоев (вкл/выкл районы и МО)

🏥 **Вкладка "Медорганизации"**
- Интерактивная таблица всех МО
- Фильтры по району и типу
- Поиск по названию

📋 **Вкладка "Данные"**
- Таблица районов с площадью
- Общая статистика

## 🔍 Проверка работы:

После запуска откройте в браузере и убедитесь:

## ❗ Возможные проблемы и решения:

### Ошибка: "Cannot find shapefile"
**Решение:** Убедитесь, что ВСЕ файлы шейпа (.shp, .shx, .dbf, .prj, .cpg) находятся в `data/geodata/`

### Ошибка при установке пакета `sf`
**Решение (Windows):** 
```r
# Может потребоваться Rtools
# Скачайте с https://cran.r-project.org/bin/windows/Rtools/
```

### База данных создана, но нет полигонов
**Решение:** Пересоздайте БД:
```r
source("launcher.R")
# Выберите опцию 2 (Пересоздать базу данных)
```

### Приложение не открывается
**Решение:** Проверьте консоль R на наличие ошибок:
```r
# Запустите напрямую:
shiny::runApp("app.R")
```
