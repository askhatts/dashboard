# План доработок v2: скрининги, индикатор Б, карта и графики

Документ фиксирует изменения по 8 задачам для реализации в приложении.

## 1) Контроль полноты загрузки Excel
- Добавить подсчет: `total_rows`, `valid_rows`, `invalid_rows`, `duplicated_rows`, `saved_rows`.
- Логировать причины брака по каждой строке (номер строки + причина).
- После загрузки выводить отчет о результате импорта и возможность выгрузки протокола ошибок.
- Сохранять журнал импортов в SQL.

## 2) Ручной ввод: листание и редактирование
- Перевести экран ручного ввода на табличный режим с вертикальной/горизонтальной прокруткой.
- Добавить пагинацию, сортировку, поиск и фильтры.
- Реализовать редактирование загруженных строк с валидацией и кнопками сохранения/отмены.
- Реализовать batch-обновление на backend транзакционно.

## 3) Подвкладки по типам скрининга
- В блоке ручного ввода добавить отдельные подвкладки по каждому типу скрининга.
- Фильтрацию и состояние таблиц хранить отдельно для каждой подвкладки.
- Новые/редактируемые записи автоматически привязывать к активному типу.

## 4) Доступность скринингов в Индикаторе Б
- Добавить агрегированные показатели скринингов в источник Индикатора Б.
- Обновить API списка доступных метрик для карты/графиков.
- Поддержать агрегацию по МО и периоду (год/месяц).

## 5) Данные скринингов в popup по МО
- Расширить popup: план/факт, просрочка, задержки, тренд.
- Показывать значения выбранных Индикатора А и Б в одном формате.
- Добавить fallback "нет данных за период".

## 6) SQL-сохранение по годам/месяцам + перезапись
- Ввести периодную модель хранения: `year`, `month` (месяц nullable для годовых данных).
- Добавить уникальность по бизнес-ключу периода/МО/типа/метрики.
- При повторной загрузке за существующий период показывать вопрос о перезаписи.
- Реализовать режим проверки конфликта (`dry-run`) и безопасный `upsert`/перезапись.

## 7) Мониторинг риска по районам
- Ввести набор риск-метрик: низкий охват, просрочка, задержки, эпид-показатели.
- Добавить risk-score по МО/периоду.
- На карте сделать режим подсветки рисков; в графиках — рейтинг проблемных МО.

## 8) Исправление геопозиционирования МО
- Приоритет точечных координат МО над центроидом полигона.
- Центроид использовать как fallback, если координаты отсутствуют/некорректны.
- Проверить сопоставление МО↔геометрия и отдельно верифицировать отображение г. Семей.

## Критерии готовности
1. После импорта пользователь видит точный отчет: сколько строк загружено/отклонено и почему.
2. Загруженные строки можно просматривать и редактировать в ручном вводе.
3. Типы скринингов разделены на отдельные подвкладки.
4. Скрининги доступны в выборе Индикатора Б и отражаются на карте/графиках.
5. Popup по МО показывает показатели скринингов.
6. Данные хранятся с периодом, повторная загрузка за период запрашивает подтверждение перезаписи.
7. Есть режим мониторинга рисковых районов.
8. Координаты МО отображаются корректно (включая г. Семей).
